Privacy policy

Last updated: October 10, 2026

Funhouse Tube is a personal tool used only by its operator on their own home computer.

What it accesses

With the operator's permission, it uses the YouTube Data API to list the videos in one of the operator's own playlists and to remove watched videos from that playlist.

What it stores

The sign-in token and a list of watched video IDs are stored only on that home computer. Nothing is sold, shared, sent to third parties, or used for advertising.

Removing access

Access can be revoked at any time at https://myaccount.google.com/permissions. Deleting the stored token on the home computer removes all saved data.

Funhouse Tube's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
